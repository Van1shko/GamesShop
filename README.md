# EzGameStore

Учебный онлайн-магазин цифровых игр на PHP и MySQL для портфолио.

## Что есть

- каталог игр с поиском, фильтрами и сортировкой;
- страница игры;
- корзина на сессиях;
- регистрация и вход;
- оформление заказа;
- админ-панель с CRUD для игр;
- подготовленная SQL-схема и демо-данные.

## Запуск

1. Скопируй проект в `htdocs` или папку локального PHP-сервера.
2. Создай базу через файл `sql/schema.sql`.
3. Проверь настройки подключения в `config.php`.
4. Открой `http://localhost/EzGameStore/index.php`.
